Electronics and Robotics Curriculum (30 Classes)

Course Overview

Phase 1: Electronics Foundation (F2F)

  • Lesson 1: Electricity Basics - Current, voltage, resistance, DC vs AC, LED polarity, Ohm's Law, first LED circuit
  • Lesson 2: Components and Circuits - Breadboard, resistors, LEDs, switches, series vs parallel circuits, manual LED system
  • Lesson 3: Motors Introduction - DC motor basics, battery-powered motor, direction change, first motion system
  • Lesson 4: Switches and Control Logic - Push buttons, ON/OFF systems, simple circuit logic
  • Lesson 5: Arduino Basics - Uploading code, digital output, blink LED
  • Lesson 6: Analog Signals - Potentiometer, analog vs digital, LED brightness control

Phase 2: Python Introduction (F2F Start)

  • Lesson 7: Python for Robotics - Python role in robotics, serial communication concept, PySerial, first Python to LED control

Phase 3: Python Controlled Systems

  • Lesson 8: Python Digital Output - LED ON/OFF control
  • Lesson 9: Python Traffic Light System - Red, yellow, green sequencing
  • Lesson 10: Python Input Logic - Button input to Python decision
  • Lesson 11: PWM Control (Python) - LED brightness control
  • Lesson 12: Python Motor Control - Motor ON/OFF

Mini Project 1: Smart Traffic Light System

Phase 4: Robot Movement

  • Lesson 13: Motor Speed Control - PWM motor control
  • Lesson 14: Dual Motor System - Left/right motor coordination
  • Lesson 15: Robot Movement Logic - Forward, backward, turn

Mini Project 2: Basic Python-Controlled Robot

Phase 5: Sensor Systems

  • Lesson 16: Ultrasonic Sensor Basics - Distance measurement
  • Lesson 17: Obstacle Detection - Motor stop logic

Mini Project 3: Obstacle Avoidance Robot

  • Lesson 18: Temperature Sensor - Heat detection
  • Lesson 19: LDR Light Sensor - Light response systems
  • Lesson 20: Sensor Combination - Multiple inputs together

Mini Project 4: Smart Environment System

Phase 6: Automation and Intelligence

  • Lesson 21: LCD Display Output - Real-time data display
  • Lesson 22: Python Automation Rules - IF/ELSE logic systems
  • Lesson 23: Multi-sensor Decision Making - Sensor fusion
  • Lesson 24: Control Panel Design - Python command interface

Mini Project 5: Smart Python Control System

Phase 7: Advanced Robotics

  • Lesson 25: Autonomous Robot Logic - Self-decision systems
  • Lesson 26: Manual vs Auto Mode - Switching control modes
  • Lesson 27: System Debugging - Fixing hardware/software issues
  • Lesson 28: Robot Behaviour Tuning - Improving performance
  • Lesson 29: Full System Integration - Motors + sensors + Python together
  • Lesson 30: Final Project - Motors, sensors (ultrasonic + temp/light), Python control system, decision-making logic, real-time response

Mini Project Summary (based on age)

  • Stage 1: Traffic Light System
  • Stage 2: Basic Robot Movement
  • Stage 3: Obstacle Avoidance Robot
  • Stage 4: Smart Environment System
  • Stage 5: Python Control System
